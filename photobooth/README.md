# 一刻 Photobooth

参考「悦时刻 photobooth」类大头贴小程序流程做的**个人零后端**版本：选版式 → 倒计时连拍 → 选片 → 滤镜/边框 → 生成竖条 → 保存相册。

## 费用（个人最省）

| 项目 | 费用 |
|------|------|
| 注册个人小程序 | 0 |
| 备案 | 0 |
| 服务器 / 云开发 | **不需要**（本地相机 + Canvas） |
| 上线后经常性费用 | **约 0 元/月** |

> 无法打开你发的 `#小程序://…` 链接做像素级还原，按同类大头贴产品的核心交互实现。若你有截图，可继续对齐 UI。

## 目录

```
photobooth/
├── app.js / app.json / app.wxss   # 微信小程序入口
├── pages/                        # 首页 → 版式 → 连拍 → 选片 → 装饰 → 结果
├── utils/                        # 版式、滤镜、Canvas 合成
└── web-demo/                     # 浏览器可演示版（同流程）
```

## 微信小程序用法

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 导入本目录 `photobooth/`（不是仓库根目录）
3. AppID 可用测试号；正式发布换成你的个人小程序 AppID
4. 真机调试需授权相机、相册

## 浏览器演示

```bash
cd photobooth/web-demo
python3 -m http.server 8765
# 打开 http://127.0.0.1:8765
```

无摄像头时会自动用占位图走完流程。

## 功能清单

- 4 种版式：经典四格 / 三连拍 / 四宫格 / 双人并排
- 倒计时连拍 + 闪光反馈
- 6 种滤镜、6 种边框色
- Canvas 合成分条并落款日期
- 保存到相册（小程序）/ 下载 JPG（Web）

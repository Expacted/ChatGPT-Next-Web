# 一刻 · PHOTO BOOTH

参考「悦时刻 PHOTO BOOTH」竞品结构的个人版小程序：**首页 / 预约 / 动态 / 我的** 四 Tab + 价目表 + 分享推广 + 微信预约提醒。现场大头贴拍摄仍保留在「现场体验」。

## 信息架构（对齐竞品）

| Tab / 页 | 内容 |
|----------|------|
| 首页 | 品牌头图、电话、四宫格入口、介绍/价目卡片 |
| 预约 | 活动类型、意向时长、日期、城市、联系人、微信提醒 |
| 动态 | 店铺动态信息流（先本地示例数据） |
| 我的 | 顾客身份、我的订单、分享推广、现场体验 |
| 价目服务表 | 租赁套餐 / 早鸟价 / 定金与服务说明 |
| 品牌介绍 | 卖点说明 |
| 现场体验 | 原连拍大头贴流程（相机 + Canvas） |

## 费用

- 展示 + 预约需求单：可先本机存储，**0 服务器费**
- 微信提醒：开通云开发后按量；个人轻量通常先用免费额度

## 微信提醒

1. 云开发集合 `bookings`
2. 部署 `createBooking`、`sendBookingReminder`
3. 配置订阅消息模板，填写 `utils/config.js` 的 `cloudEnvId`、`bookingRemindTmplId`

## 使用

微信开发者工具导入 `photobooth/` 目录。

网页演示：

```bash
cd photobooth/web-demo && python3 -m http.server 8765
```
